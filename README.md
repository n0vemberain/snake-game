ওয়েব ব্রাউজারে সরাসরি খেলার জন্য একটি আধুনিক, নিয়ন সাইবারপাঙ্ক লুকের সম্পূর্ণ আর্কেড **স্নেক গেম (Snake Game)**। এতে রয়েছে রেট্রো ৮-বিট অডিও সিন্থেসাইজার, ফিজিক্স-ভিত্তিক পার্টিকেল ইঞ্জিন, একাধিক গেম মোড, বিশেষ পাওয়ার-আপস এবং টাচস্ক্রিন ডিভাইসের জন্য অন-স্ক্রিন ভার্চুয়াল কন্ট্রোলার।

---

## ✨ প্রধান বৈশিষ্ট্যসমূহ (Key Features)

### 🎮 ৪টি রোমাঞ্চকর গেম মোড (Game Modes)
1. **ক্লাসিক (Classic):** ঐতিহ্যবাহী স্নেক গেমপ্লে — যেখানে কোনো বাধা ছাড়াই খাবার খেয়ে সাপের দৈর্ঘ্য বাড়ানোর চ্যালেঞ্জ।
2. **লেভেলস / ক্যাম্পেইন (Campaign Levels):** প্রতি ৫টি খাবারে লেভেল আপ ও নতুন জটিল দেয়াল বাধার আবির্ভাব।
3. **স্পিড রান (Speed Run):** ৬০ সেকেন্ডের কাউন্টডাউন টাইমার। প্রতিটি খাবার সময়ের সাথে বোনাস সেকেন্ড যোগ করে।
4. **পোর্টালস (Portals):** স্ক্রিনের দুই প্রান্তে অবস্থিত রহস্যময় নিয়ন পোর্টাল দিয়ে সাপের টেলিপোর্টেশন মেকানিক্স।

---

### 🎨 ৫টি ডায়নামিক আর্কেড থিম (Arcade Themes)
- ⚡ **সাইবার নিয়ন (Cyberpunk Neon):** সায়ান ও ম্যাজেন্টা রঙের ফিউচারিস্টিক ভাইব।
- 🌆 **সিন্থওয়েভ ৮০s (Synthwave 80s):** রেট্রো সানসেট গোলাপি ও পার্পল গ্রাফিক্স।
- 👾 **রেট্রো গেমবয় (Retro Gameboy):** ক্লাসিক নস্টালজিক সবুজ পিক্সেল আর্ট।
- 💻 **দ্য ম্যাট্রিক্স (The Matrix):** টার্মিনাল গ্রিন হ্যাকার ফিল।
- 🌙 **মিডনাইট ডার্ক (Midnight Dark):** স্লিক মিনিমালিস্টিক ডার্ক মোড।

---

### 🔊 প্রসিডিউরাল ওয়েব অডিও সিন্থেসাইজার (Web Audio API Sound)
- কোনো বাহ্যিক `.mp3` বা `.wav` অডিও ফাইলের প্রয়োজন নেই!
- ব্রাউজারের নিজস্ব **Web Audio API** ব্যবহার করে রিয়েলটাইমে ৮-বিট সাউন্ড সিন্থেসাইজ করা হয় (চিম, ব্লিপ, লেজার সুইপ, ক্র্যাশ এক্সপ্লোশন এবং ফ্যানফেয়ার)।
- শূন্য নেটওয়ার্ক লেটেন্সি এবং তাত্ক্ষণিক অডিও প্লেব্যাক।
- এক ক্লিকে সম্পূর্ণ অডিও মিউট/আনমিউট করার সুবিধা (লোকালস্টোরেজে স্টেট সেভ থাকে)।

---

### 🍎 বিশেষ খাবার ও পাওয়ার-আপ বাফার (Special Foods & Power-Ups)
- 🔴 **সাধারণ আপেল:** ১০ পয়েন্ট ও ১ ঘর দৈর্ঘ্য বৃদ্ধি।
- 🌟 **সোনালী আপেল (Golden Star):** ৫০ বোনাস পয়েন্ট (নির্দিষ্ট সময় পর স্বয়ংক্রিয়ভাবে উধাও হয়)।
- ⚡ **স্পিড থান্ডার (Speed Boost):** ৭ সেকেন্ডের জন্য সাপের গতি দ্বিগুণ ও অতিরিক্ত পয়েন্ট মাল্টিপ্লায়ার।
- 👻 **ঘোস্ট বেরি (Ghost Phasing):** ৭ সেকেন্ডের জন্য দেয়াল ও নিজের শরীরে কোনো আঘাত ছাড়াই অতিক্রমের ক্ষমতা।
- ❄️ **আইস ক্রিস্টাল (Ice Freeze):** সাপকে সাময়িক ধীরগতির করে কঠিন পরিস্থিতিতে নিয়ন্ত্রণ সহজ করে।

---

### 💥 পার্টিকেল ও স্ক্রিন-শেক ভিজ্যুয়াল এফেক্ট
- খাবার খাওয়ার মুহূর্তে রঙিন স্ফুলিঙ্গ ও তারার বিস্ফোরণ।
- সাপের মৃত্যুর সময় আকর্ষণীয় ফ্র্যাগমেন্ট এক্সপ্লোশন।
- সংঘর্ষ এবং লেভেল আপে আর্কেড-স্টাইল স্ক্রিন শেক (Screen Shake) ফিজিক্স।
- চলার পথে সাপের মাথার পেছনে নিয়ন ট্রেইল লাইট।

---

### 📱 সম্পূর্ণ রেসপনসিভ ও মোবাইল সমর্থন
- কম্পিউটার, ল্যাপটপ, ট্যাবলেট এবং স্মার্টফোনের স্ক্রিনের সাথে স্বয়ংক্রিয়ভাবে মানানসই।
- মোবাইল ব্যবহারকারীদের জন্য নিচে নিবেদিত **ভার্চুয়াল D-Pad** ও অ্যাকশন বাটন।
- ক্যানভাসে সরাসরি **টাচ সোয়াইপ (Swipe Gesture)** করে সাপের দিক পরিবর্তনের সুবিধা।

---

### 🏆 পরিসংখ্যান ও অর্জন (Achievements & Highscore)
- বর্তমান স্কোর, সাপের দৈর্ঘ্য এবং খেলার সময় ট্র্যাকিং।
- **সর্বোচ্চ স্কোর (High Score)** স্বয়ংক্রিয়ভাবে ব্রাউজারের `localStorage`-এ সংরক্ষিত থাকে।
- ৮টি বিশেষ আনলকযোগ্য মেডেল ও টোস্ট নোটিফিকেশন ব্যানার।
- এক ক্লিকে বন্ধুদের সাথে সোশ্যাল শেয়ার বা ক্লিপবোর্ডে স্কোর কপি করার বোতাম।

## 🚀 যেভাবে চালাবেন (How to Run Locally)

কোনো প্রকার ডিপেন্ডেন্সি বা `npm install` করার প্রয়োজন নেই! এটি সম্পূর্ণ পিওর Vanilla Web প্রযুক্তিতে তৈরি।

### পদ্ধতি ১: সরাসরি ব্রাউজারে চালু
যেকোনো ফাইল এক্সপ্লোরার থেকে `index.html` ফাইলে ডাবল-ক্লিক করলেই আপনার পছন্দের ব্রাউজারে গেমটি চালু হয়ে যাবে।

### পদ্ধতি ২: লোকাল সার্ভার ব্যবহার করে (প্রস্তাবিত)
টার্মিনালে প্রজেক্ট ডিরেক্টরিতে গিয়ে যেকোনো একটি কমান্ড রান করুন:

**পাইথন ব্যবহার করে:**
```bash
python3 -m http.server 8080
```
এরপর ব্রাউজারে প্রবেশ করুন: `http://localhost:8080`

**অথবা Node.js (npx) ব্যবহার করে:**
```bash
npx serve
```

## 🛠️ ব্যবহৃত প্রযুক্তি (Tech Stack)
- **HTML5:** ক্যানভাস ও সেমান্টিক মার্কআপ (`<dialog>`, `<header>`, `<canvas>`)
- **CSS3:** Custom Variables, CSS Grid & Flexbox, Backdrop-filters, Keyframe Animations
- **Modern JavaScript (ES6+):** Class-based Modular Architecture, RequestAnimationFrame Loop, LocalStorage API, Web Share API
- **Web Audio API:** Oscillator Nodes, Gain Envelopes, Noise Buffers for real-time sound synthesis
